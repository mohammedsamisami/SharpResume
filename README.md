# SharpResume

SharpResume is a free and powerful resume builder that allows anyone to create a modern professional resume easily. This project was created as a **mini project** for **Navodaya Institute of Technology** by **Mohammed Sami and Team**.

The goal of SharpResume is to help students and professionals create professional resumes that are ATS-friendly and ready for job applications.

---

## ⚒️ Resume Builder

SharpResume's resume builder allows users to create a modern professional resume quickly.

![Resume Builder Demo](https://i.ibb.co/jzcrrt8/resume-builder-demo-optimize.gif)

### Core Features
| **Feature** | **Description** |
|---|---|
| **1. Real-Time Updates** | The resume PDF updates in real-time as you enter your information, so you can instantly see the final output. |
| **2. Modern Professional Design** | The resume follows professional standards and is ATS-friendly, ensuring consistency in fonts, sizes, margins, and bullet points. |
| **3. Privacy-Focused** | All data is stored locally in your browser, so no sign-up is required and your personal information never leaves your device. |
| **4. Import Existing Resume** | You can import an existing resume PDF and quickly update it to a modern, professional design. |
| **5. Proven Effectiveness** | Users have successfully landed interviews and job offers using resumes created with SharpResume. |

---

## 🔍 Resume Parser

SharpResume also includes a resume parser to test and confirm your resume's ATS readability.

![Resume Parser Demo](https://i.ibb.co/JvSVwNk/resume-parser-demo-optimize.gif)

The parser helps you see how applicant tracking systems (ATS) will read your resume, ensuring better chances in job applications.

## 📁 Project Structure

SharpResume is built using the NextJS framework. Key pages include:

| **Page Route** | **Description** |
|---|---|
| / | Home page with hero section, auto-typing resume demo, steps, testimonials, and more |
| /resume-import | Page to import existing resume PDF and update it to SharpResume format |
| /resume-builder | Page to build and download your professional resume PDF |
| /resume-parser | Page to test the ATS readability of your resume |

## 📌 How to Use

1. Clone or download the project  
2. Open in your favorite code editor  
3. Start the development server (`npm install` → `npm run dev`)  
4. Open [http://localhost:3000](http://localhost:3000) in your browser to see SharpResume in action
5. Want to try..?
6. https://sharp-resume-tau.vercel.app/ 

> SharpResume requires no sign-up and keeps your data fully private.
